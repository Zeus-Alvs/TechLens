Dashboard de telemetria de hardware em tempo real criado para o isolamento e monitoramento de dados dinâmicos de sensores.

**Engenharia & Arquitetura:**
- **Simulação & API:** Desenvolvimento de um daemon gerador de ondas de estresse e uma API RESTful de alta performance orquestrada em Python via FastAPI.
- **Cache Local & Persistência:** Implementação do banco de dados Redis executado nativamente em ambiente conteinerizado Docker.
- **Interface Reativa:** Construção de um front-end em Next.js com implementação de Cache Global para garantir o processamento fluido de métricas críticas.
